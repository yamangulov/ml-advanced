# Распознавание рукописных символов EMNIST

## Описание проекта

Этот проект представляет собой сервис для распознавания рукописных символов с использованием датасета EMNIST. Проект состоит из двух основных частей:

1. **Ноутбук для обучения модели** (`prepare_model.ipynb`) - содержит код для загрузки данных, предобработки, обучения модели и сохранения ее в файл.
2. **Веб-сервис** - FastAPI приложение, которое принимает изображения и возвращает распознанные символы.

## Технические характеристики

- **Датасет**: EMNIST Balanced (47 классов: 10 цифр + 37 букв)
- **Модель**: SVM
- **Точность**: >82% на тестовой выборке
- **Формат входных данных**: Изображения 28x28 пикселей в оттенках серого
- **Формат выходных данных**: Распознанный символ (строка)

## Установка и запуск

### Локальный запуск

1. Установите зависимости:
pip install -r requirements.txt

2. Обучите модель (если нужно):
jupyter notebook prepare_model.ipynb
# Запустите все ячейки ноутбука

3. Запустите веб-сервис:
uvicorn myapp.main:app

4. Откройте в браузере:
http://localhost:8000

### Запуск в Docker

1. Постройте Docker-образ:
docker build -t emnist-app .

2. Запустите контейнер:
docker run -p 8000:8000 emnist-app

3. Откройте в браузере:
http://localhost:8000

## Использование API

Сервис предоставляет один endpoint для распознавания:

**POST /api/predict**
- Вход: JSON с полем `image` - строка с пикселями изображения в формате "[p1,p2,p3,...,p784]"
- Выход: JSON с полем `prediction` - распознанный символ

Пример запроса:
curl -X POST "http://localhost:8000/api/predict" \
     -H "Content-Type: application/json" \
     -d '{"image": "[0,0,0,...,255]"}'

## Использование приложения

После открытия приложения в браузере по адресу `http://localhost:8000`:

1. Нарисуйте символ (букву или цифру) в области для рисования с помощью мыши или сенсорного ввода
2. Нажмите кнопку "Распознать" для отправки изображения на сервер
3. Приложение автоматически преобразует нарисованное изображение в формат, понятный модели
4. Результат распознавания отобразится на экране
5. При необходимости можно очистить область рисования и попробовать снова

Приложение использует HTML5 Canvas для захвата рисунка, преобразует его в массив пикселей и отправляет на API endpoint `/api/predict` для распознавания.

Однако, дефекты рисования в canvas приводят к тому, что символы все равно очень сильно отличаются от символов emnist, и фактически данная модель предсказывает не то, что нарисованные символы являются одним из допустимых символов ASCII, а только то, насколько нарисованные символы близки по стилю рисования одному из символов emnist - несмотря на то, что модель на тестовых данных дает очень высокую точность более 0.82. Я немного поработал над фронтом, чтобы адапатировать его для лучшего рисования, но все равно сделать рукописные цифры максимально похожими на символы emnist - это задача практически недостижимая. То есть я хочу сказать, что использование emnist для распознавания символов - это очень несовершенный подход сам по себе, и нужны другие подходы для лучших результатов с реальным фронтендом.
